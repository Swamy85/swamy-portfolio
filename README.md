# Kotari Swamy · Portfolio

A responsive React portfolio highlighting full-stack development, AI projects, education, and contact information.

## Run locally

```sh
npm install
npm start
```

## Production build

```sh
npm run build
```

Create React App generates the deployable site in `build/`. It copies files from `public/` and bundles the React source from `src/`; do not edit generated files in `build/` directly. The build folder is ignored by Git and can be recreated whenever needed.

## Project structure

- `src/components/` — portfolio sections and navigation
- `src/assets/` — images used by React components
- `public/` — resume, certificate PDFs, site metadata, and favicon

Update project and profile content in the corresponding component before rebuilding.
